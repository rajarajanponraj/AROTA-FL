# Project Audit: AROTA-FL

## 1. Executive Summary
This audit provides a comprehensive inventory, classification, and gap analysis of the **AROTA-FL** (Convergence-Aware Active RIS for AirComp-Based Federated Learning) repository. Every accessible source file, script, dataset, figure, derivation note, and manuscript artifact has been inspected to establish an uncompromised evidence baseline prior to drafting the publication-quality IEEE manuscript.

### 2.2 Core Source Modules (`src/`)

  - `channel_estimation.py` (0.6 KB) — *Relevant*: Additive bounded/Gaussian CSI error injector ($\hat{h} = h + e$, $e \sim \mathcal{CN}(0, \sigma_e^2 I)$).

- **`src/ris/`**:
  - `active_ris.py` (1.5 KB) — *Relevant*: Active RIS reflection and amplification model with thermal noise generation ($n_R \sim \mathcal{CN}(0, \sigma_R^2 I_N)$).

  - `phase_control.py` (0.6 KB) — *Relevant*: Phase alignment routines.
  - `ris_power.py` (0.3 KB) — *Relevant*: RIS incident and reflected power budget computation.
- **`src/aircomp/`**:
  - `beamforming.py` (1.4 KB) — *Relevant*: Zero-Forcing (ZF) transmit power scaling $b_k = \frac{\alpha_k}{c \hat{h}_k^{eff}}$ and receive normalization $c = \max_k \frac{\alpha_k}{\sqrt{P_k} |\hat{h}_k^{eff}|}$.

  - `mse.py` (2.6 KB) — *Relevant*: Analytical closed-form MSE computation and expected MSE bounding function ($J_t$).
  - `aggregation.py` (1.5 KB) — *Relevant*: Physical-layer to federated learning bridge mapping wireless analog symbols to neural network tensor weights.
- **`src/optimization/`**:
  - `convergence_aware.py` (4.0 KB) — *Relevant / Core Novelty*: Multi-start SLSQP / L-BFGS-B optimizer minimizing the convergence-aware objective $J_t(x)$ subject to individual power budgets $P_{\max}$ and active RIS output power constraints $P_{\text{RIS},\max}$.

- **`src/federated_learning/`**:

  - `client.py` (2.9 KB) — *Relevant*: Client local training engine with cross-entropy loss, SGD optimizer, local epochs, and weight difference calculation.
  - `server.py` (2.5 KB) — *Relevant*: Parameter server coordinating rounds, broadcasting weights, and testing test set accuracy and loss.

## 3. Discrepancy Analysis and Evidence Gaps

1. **Authorship and Metadata Discrepancy**:
   - `docs/dreft/draft.tex` contained placeholder authors: `Author 1, Author 2, and Author 3 \cite{long2021active}`.
   - *Resolution*: As mandated, do not invent artificial affiliations. Present authoritative manuscript titling and academic structure aligned with IEEE conference/transactions formatting.

2. **Citation Key Mismatch in Earlier Draft**:
   - `docs/dreft/draft.tex` used an informal manually typed `\thebibliography` environment with keys such as `\bibitem{long2021active}` while the comprehensive, peer-reviewed `.bib` database uses unique identifiers like `ruizhe_long_83e9453a`.
   - *Resolution*: Unify citations strictly against the validated BibTeX database (`references.bib`) in `manuscript/`.

3. **Incomplete Mathematical Formulations in Earlier Draft**:
   - The earlier draft listed qualitative terms like `Penalty(\sigma_e^2, \alpha, \mathbf{b})` instead of the rigorous analytical expression $|c|^2 \|G^H \Theta\|^2 \sigma_e^2 \sum_{k=1}^K |b_k|^2$.
   - *Resolution*: Include complete closed-form equations verified against `theory/derivations.md` and `src/aircomp/mse.py`.

4. **Page Count Deficit in Existing Draft**:
   - The draft in `docs/dreft/draft.tex` is only ~217 lines, filling approximately 2.5 pages when compiled.
   - *Resolution*: Expand the manuscript systematically across all IIMRaD sections to achieve a complete, mathematically thorough, technically rigorous 5-page IEEE publication standard.

5. **Direct Link Blockage vs Direct Link Modeling**:
   - Codebase models both direct link $h_{direct}$ and RIS cascaded link $G^H \Theta h_{ris}$. The derivations discuss direct link blockage as the default motivated scenario while retaining the general formulations.
   - *Resolution*: Clearly state both: primary evaluations focus on the severe-blockage scenario where active RIS provides crucial connectivity, while the mathematical framework seamlessly accommodates direct channel components.
